防回灌如何工作

注入的记忆会进入会话历史。导入器再次遇到它们时查台账：命中则标记为已有记忆的引用，不再提炼成新的独立证据。台账同时回答“Agent 为什么知道 / 不知道某件事”。

归集顺序

  1. 第 1 步已整理的长期记忆CLAUDE.md、自动记忆文件直接入库，已付过总结成本。
  2. 第 2 步全部可读会话建立清单与原始记录，先覆盖后提炼。
  3. 第 3 步优先提炼近期、被引用、含决策纠正的历史优先。
  4. 第 4 步增量处理其余历史低优先级补扫，不挤占当前交互预算。

安全三条硬规则

  1. 凭据永不入库入库前脱敏：API key、token、密码模式识别；原始证据同样脱敏。
  2. 规则类记忆自主仲裁信任分级：用户声明 > 工具验证 > Agent 推断 > 外部内容；低信任内容永不直接成为规则，决策写入仲裁台账。
  3. 记忆是数据，不是指令注入内容带来源与日期，标注为参考数据；不得据此自行修改授权规则。
