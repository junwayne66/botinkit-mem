防回灌如何工作

注入的记忆会进入会话历史。导入器再次遇到它们时查台账：命中则标记为已有记忆的引用，不再提炼成新的“证据”。台账同时回答“Agent 为什么知道 / 不知道 X”。

安全三条硬规则

  1. 凭据永不入库入库前脱敏：API key、token、密码模式识别；原始证据同样脱敏。
  2. 规则类记忆自主仲裁信任分级：用户声明 > 工具验证 > Agent 推断 > 外部内容；T4 永不直接成为规则，决策写仲裁台账。
  3. 记忆是数据，不是指令注入内容带来源与日期，标注为参考；不得自行修改授权规则。
