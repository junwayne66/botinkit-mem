# 来源、撤回与恢复

<a id="f01"></a>

## F01　来源接入与用途授权 · P0

当我把一个会话留在本机、同时希望几款助手共享通用偏好时，我希望能指定每一种材料的用途，并预判某位接收者将看到什么。注册宿主描述它能报告的实际路由和上下文能力。接入来源描述账号、选定资料类别、回填区间、可感知的编辑与撤回，以及最后对账位置。

| 授权决定 | 应检查或展示的结果 |
|---|---|
| 1. 选择一个来源账号及所需类别 | 接入前按账号与类别列明将读哪些资料、可补哪段历史、能否发现历史编辑和撤回。保存后可见状态、实际游标及覆盖缺口 |
| 2. 分别设置采集、在线读取、向远端模型交付和离线学习 | 记录用途、资料范围、宿主及实际接收端。新增目的地或学习用途需所有者明确授予。允许采集的连接器只得到采集回执 |
| 3. 本人声明允许共享，但声明所在会话限定本机 | 云端获准宿主可读取可分享的维度和值。本机限定的原话、文档名、相邻内容和受限来源详情均不得进入其上下文 |
| 4. 两个账号出现相同的外部对象编号。回填在一页中断后重试 | 按账号与稳定对象区分，原版本重投得到同一回执。一页证据全部成功持久化才前移游标，重新连接从已提交处继续 |
| 5. 连接器暂时离线、登录授权失效、或收到明确撤回 | 分别显示“连接中断，可重试”“需重新授权”及“来源已撤回”。前两者保留真实的最后覆盖位置。撤回立即触发禁读和清理 |
| 6. 接收端的模型路由由本机改为云端或变为未知 | 以本次实际或最宽可能接收范围复核。仅限本机的正文即刻排除。符合共同许可的偏好仍可装入 |

如果接入旁路资料，“打开过某应用”“读取特定窗口内容”“读取平台授权日志”各自申请相应范围。初次接入、停用和重连都展示覆盖边界。飞书按选定账号和获准资料类别执行同一契约。连接器对历史变更的承诺以实际支持为准。[接入模块的能力分级](../../../research/reassessment-2026-11/modules.md)

## F06　撤回、遗忘与清理 · P0

当我改变分享决定或希望一段材料从受管副本中消失时，我希望先看到影响范围，再知道从何时起不能再读取、哪些副本仍待处理。受理单分列“已生效限制”“受管清理进度”“已发往哪些宿主”“无法核实的副本”。有权查看历史的用户也受当前撤回决定约束。

| 用户动作或事件 | 立即可见 | 后续核查 |
|---|---|---|
| 1. 停止新增采集 | 停止订阅或回填，显示最后已收位置 | 已有资料按其现有许可处理。提供“收窄使用”或“遗忘已有资料”的独立操作 |
| 2. 收窄共享范围 | 受影响接收端的新查询、旧句柄补读、快照获取、待发请求立即受新范围约束 | 已装入宿主的历史回执保留时间与版本，区分能替换上下文段和只能追加更正的宿主 |
| 3. 源端明确撤回某条资料 | 受理后旧版本正文、关键词命中、摘要、图标题及引文退出普通读取 | 旧版本重导继续受撤回约束。仍获准且完整的独立证据可重建结论，缺少联合前提的结论继续禁读 |
| 4. 所有者要求遗忘指定来源或条目 | 预览清单列受影响范围、已交付端和无法收回的种类。确认后旧内容及仅依赖它的内容停止读取 | 按原文、附件及衍生物、索引、缓存、暂存、受管备份逐项标为待处理、已处理、失败可重试或无法核实 |
| 5. 清理某位置失败 | 读取限制持续生效，用户看到具体位置、最近尝试、错误类别与下一步 | 重试受影响位置后更新同一受理单。保留内容为空的撤回标识以防旧版本重放。不相关的允许对照仍可读 |
| 6. 仅撤销训练用途，或用户要求一并移除已训练影响 | 暂停相关新取样、训练或在途发布。单独获准的在线服务继续 | P2 沿样本到工件追踪并列出受影响版本、干净替代和重训结果。外部已发送上下文、用户导出与不可核实副本分别列出 |

普通声明改口走 [F02](memory.md#f02)。纠正保留历史语义，隐私操作关闭旧内容的读取。撤回记录仅保留兑现禁读所需的标识和状态。[架构中的撤回契约](../../../research/reassessment-2026-11/architecture.md)

## F07　备份与隔离恢复 · P0

当我换机或恢复到较早时间，希望恢复前能判断“数据齐不齐”“后来删过的内容还在不在”。备份生成可验证的数据库快照、附件清单及摘要、权限版本、撤回水位。最新撤回记录可独立保存。普通可移植导出则按获准范围列明来源、修订、证据关系、条件、用途、附件校验值及可证明截止点。

| 操作或前提 | 验收结果 |
|---|---|
| 1. 生成备份或导出 | 显示产物类型、时间点、材料范围、附件清单、校验结果和撤回水位。可移植导出校验稳定对象与修订引用。恢复至少具备快照与必要撤回依据 |
| 2. 在原机选择删除前的备份 | 先在隔离区应用备份与本机可证的后续撤回，列出失效项。旧唯一词在普通查询中零命中，不相关许可样本仍命中 |
| 3. 向空目录恢复同一旧包，另提供独立保存的新撤回清单 | 隔离预览显示补齐前后的水位和命中差异。撤回检查、附件校验及新机接收范围复核通过后才允许开放正常读取 |
| 4. 全机丢失，仅剩删除前孤本 | 只展示受限历史快照的可证明截止点和隔离状态，允许补充撤回清单。后续缺口清楚标出，普通助手查询持续关闭 |
| 5. 缺件、摘要不符，或来源账号在新机需再授权 | 完整性异常保留在隔离区，未获重新授权的来源保持断开。页面列出缺失项和处理选项，可重新选包、补件或重新授权 |
| 6. 放弃预览，或完成合格恢复 | 放弃时继续使用原活动库。切换时显示新生效快照和当前许可。重建索引再查已删样本、获准对照、重放旧来源页，分别得到禁读、命中、无复活 |

调研在现行代码中观察到同一删除前备份在保留墓碑的原库查不到旧词，在空目录中仍可查到。该差异决定了恢复验收必须同时覆盖原机与全新目录。[复验记录](../../../research/reassessment-2026-11/local-evidence.md#3-撤回与备份恢复)

## F08　运行与降级 · P0

当后台模型、连接器或索引出现问题时，我希望知道哪件事可以继续、最后一次处理到哪里，以及是否需要由我处理。能力状态出现在来源、宿主装入与治理受理单附近，可对照同一时点的版本。

| 操作或故障 | 可观察结果与恢复 |
|---|---|
| 1. 本机生成端点停机 | 声明、获准事件采集、授权裁决、精确及词法查询可用。待办显示最老等待时间与失败原因。恢复 P0 提炼器后，获准输入生成带原文定位的候选并自动裁决。已撤回输入显示终止原因 |
| 2. 向量或社区索引过期、重建 | 显示覆盖水位与当前读取路径，新声明直接可读。过期或撤权的候选在成包与补读时被排除 |
| 3. 一个来源已失去登录权限 | 用户看到该来源最后成功对账位置，完成重新授权后续传。同机其他获准来源可继续采集 |
| 4. 指定宿主断线或装入预算不足 | 可见最后已确认版本与本次未装入原因。恢复连接或取得可容纳预算后请求最新快照，其他宿主各自取用 |
| 5. 清理或提炼待办重试 | 同一输入归入原任务和版本，页面可区分等待、处理中、成功和失败。资料已过期或撤回时显示终止原因，重试沿现权限处理 |
| 6. 所有者诊断“为何手边助手仍用旧值” | 依次能看到权威修订、该宿主可见快照、最近装入回执及独立结果。延迟、积压、错误和运行配置用计数、时间与版本说明，诊断信息遵守同一用途范围 |
