# 端到端产品验收

这里的输入是合成夹具，结果是预期行为。用独立测试身份和空数据目录，经普通用户入口执行。保存必要的脱敏观察，记录真实宿主能力、运行版本、时区、权限范围、用到的工件与结果回执。[功能索引](README.md) · [调研中的评测方法](../../../research/reassessment-2026-11/evaluation.md)

## P0 第一步　更正一项，另一助手实际装入

所有者在本机管理台输入两条声明。云杉与白桦分别代表两种合成授权配置。云杉在获准本机路由可读原句，白桦在获准云端路由只读共享偏好。可用测试接收端验证两种配置的载荷裁剪。首轮真实宿主指定为 Claude Code 与 Codex，分别登记其实际路由、装入能力与接收许可，核查两者装入与实际产出。不得凭夹具名称把任一真实云端路由视为本机。可选的第三个客户端仅支持显式查询。

| 步骤 | 操作 | 必查结果 |
|---|---|---|
| 1 · U4 | 允许两端读取可共享的本人声明，原会话限定本机。原会话另留一行唯一的合成词“松果纸页七”，不把该行纳入共享声明 | 授权预览能区分声明值、原会话及接收路由。该词只会出现在获准的本机原文读取中 |
| 2 · U1 | 本机声明“所有助手的报告用中文，先列行动项” | 回执列“报告语言＝中文”“报告开头＝先列行动项”，分别取得修订。相同源消息重试一次，两项的修订均不再增加 |
| 3 · U2 | 云杉与白桦先各开一次会话并提出“汇总今天的工作” | 真实模型输入含两项当前声明。白桦的输入、补读及检索结果均不含受限附言。两端装入可定位到本次上下文，记录输出中的语言与开头 |
| 4 · U1 | 继续声明“以后报告先写结论” | 下一次获准查询即得“中文＋先写结论”。开头产生新修订且旧值可按历史回查。语言维度沿用原修订 |
| 5 · U2 | 云杉开新会话，白桦保留原会话，任务仍只给“汇总今天的工作” | 核对各端本次实际进入模型的现行声明及版本，并要求输出用中文、第一部分给结论。若有装入但输出不符，记下具体失败断言 |
| 6 · U2/U3 | 绑定本次尝试和最终产物运行上述两条断言。在另一尝试中刻意不提供结果回执 | 前者按真实结果记通过或失败，并保留具体产物。后者为未知。已提供、已装入、已采用、独立结果四者各有证据 |
| 7 · U1/U2 | 在单次任务说“这次只写一段英文”，下一次恢复普通任务。分别模拟上下文压缩、断线后重连、一年静默再启动 | 临时要求只作用于本次。每次重新建立的上下文取得仍适用的最新声明。仅查询客户端、离线宿主或未回执的会话各自显示实际能力 |

**声明切片的完成条件。** Claude Code 与 Codex 均取得当前组合，原句只出现在获准路径。保留一项原修订、一项新修订、两款真实宿主的装入回执及独立结果。所有确定性断言逐项通过。无真实回执时演示可标“已提供”，对应验收待完成。这一步完成后接入 P0 自动提炼。

## P0 第二步　从普通对话提炼，再由另一宿主取用

| 步骤 | 经真实入口执行 | 可核验的证据 |
|---|---|---|
| 1. 准备授权 | 在独立测试环境授权 Claude Code 与 Codex 的实际路由处理“溪桥／导入超时”的合成任务材料，授权后台真实提炼模型处理选定片段。安排同仓“通知文案”作为无关任务，并将另一段带唯一合成词的本机限定材料留在接收授权外 | 保存两个宿主与提炼端各自的资料范围、用途、路由、会话和任务锚点。合成授权与第一个声明场景分别登记 |
| 2. 自然工作 | Claude Code 收到普通请求“检查这轮溪桥导入停在哪一步”。对话先记录“准备复验”，让宿主实际调用测试工件，产生解析通过及入库超时的回执。之后助手转述同一次回执 | 保存真实对话消息、工具事件与工件版本。没有“记住”指令，没有手填候选、断言或经历 |
| 3. 运行基础提炼 | 用已登记的真实模型自动处理普通消息与工具回执，查看一次处理及权威仲裁结果 | 能从“解析通过”和“入库超时”回到对应工具输出位置，从计划回到其对话位置。记录模型与提炼规则版本、任务条件、是否生效和所生成的修订。助手转述沿同一根计证，未执行动作保留计划属性，失败不提升为成功。原文无权进入的处理端收不到受限片段 |
| 4. 换宿主接手 | Codex 开新会话，只收到“继续溪桥的导入排查”。让宿主取得经仲裁的经历、核对证据并执行下一步 | 记录实际装入的经历修订及采用依据。接手卡与最终产物保留“解析通过、入库仍超时”，后续动作定位写入问题。独立回执核对工件、任务和动作，确认没有混入通知文案或泄露受限内容 |
| 5. 复核边界 | 收窄 Codex 对该任务的原文权限后展开旧句柄并重新取包。另给一个缺少任务锚点的同仓请求以及一个无历史任务 | 旧句柄及新包按现授权办理，无关许可对照仍可用。缺锚点给出可区分的任务候选，无历史任务允许正常完成 |

**首发自动提炼验收。** 必须取得真实模型的候选、自动仲裁后的修订、Claude Code 源事件、Codex 实际使用与独立任务结果，缺一项即记录对应断点。模型停机时的入队与词法接手另作降级用例。P1 再按同一任务比较基本路径与增强方案，设关闭记忆、宿主文件、原文词法、完整方案及给定充分证据的诊断组，控制读取模型、工件、工具、步数及上下文预算。

|---|---|---|---|
| A01 · P0 | 按首切先声明、只改开头、重开/压缩/重连、临时例外。另用宿主中核实过的本人消息和 CLI 各追加一次主题不同的声明 | 逐项回执、现行/历史组合、实际装入与输出。各入口只能向前追加表达 | F02、F03、F11 |
| A02 · P0 | 同一回填页重复投递一次，撤回其中一条再重导。同时保留另一条获准记录 | 稳定回执、游标、撤回版本、禁读与允许两组结果。断网期间标明缺口而非确认为删除 | F01、F06、F08 |
| A03 · P0 | 用 Claude Code 产生任务证据，Codex 运行上述实际接手。撤去接收端的原文许可后再次展开先前句柄 | 接手卡、经仲裁的经历修订、实际采用的引用和任务断言。权限变更后旧句柄禁读，独立获准记录仍可打开 | F03、F04、F05、F09、F11 |

| A05 · P0 | 遗忘带唯一合成词的来源，暂停清理，查询词法、摘要、详情、旧句柄、待交付包。恢复清理 | 受理时立即禁读。未处理位置与失败原因分别可见，历史已发副本有边界，合法对照仍命中。已启用派生出口逐个复验 | F01、F06、F08 |
| A06 · P0 | 删除前快照依次在原机、有新撤回清单的空目录、仅剩旧包的空目录中恢复，另测试缺一份附件 | 前两组在对齐撤回后旧词零命中且许可对照可读。第三组限定历史预览。缺件时阻止开放普通查询 | F06、F07 |

| A09 · P1 | 两个项目有同名桥接器。用近义词问多跳问题，再撤去一项联合前提。关闭社区 | 各跳有授权证据或明确缺口。受限标题、计数及摘要均不外露。精确现值与词法检索在社区关闭时仍可用 | F05、F06、F10 |
| A10 · P2 | 同一任务多次改写且另有仅获准在线的样本。生成数据快照，运行旁路候选和受控试用 | 同源簇仅在一个划分，在线样本被排除，冻结结果与试用任务以各自分母呈现，弱信号未变成强标签 | F01、F11、F12 |

P0 首发验收包括声明切片、真实基础提炼接手及 A01–A08、A12。P1 在通过 A08 的基础上，以不同任务和版本中的成功、失败及反例检验跨案例方法归纳，与基础提炼器配对比较漏提、错归因、误归并及成本，再执行 A09。P2 按 A10、A11 检查学习与发布。尚未部署或缺观察的出口单列，静态样稿、合成回执和隔离协议验证与两款真实宿主结果分别记录。
