## 哪些判断还要实测

| 调研里的观察 | V2 需要回答的问题 |
|---|---|
| 在都有消息标注的 438 题中，单条消息词法检索在前五个会话中找全金标会话的有 369 题，送出的最高分消息在各金标会话都带标注的有 203 题 | 固定候选、读者和 token 预算后，补哪段原文能让助手拿到完整动作与结果？分别记录证据覆盖和任务是否成功。[检索基线](../../research/reassessment-2026-11/local-evidence.md) |

**首发范围由所有者于 2026-11-19 补充确认。** 声明闭环先集成，普通对话与工具回执的自动提炼随后接入，两项均须在首个日用版本验收。第一轮真实跨助手组合为 Claude Code 与 Codex。云杉、白桦仅用于原型演示不同接收权限。

阶段 P0/P1/P2、V2 API 名称、页面结构与合成原型属于本轮设计。模型选择、向量维度、社区算法、性能数值和学习收益留给固定预算的对照评测。原研究引用的已有测试和公开数据结果均保留其原有分母、工作树和验证对象。

**同日补充的运行要求。** 三端统一使用 `bmem` 命令和 `~/.bmem` 工作目录，CLI 与本机网页均可配置连接器和模型。初始化提供已有模型 API 或本地 Ollama 两条路径。向量相似检索默认关闭，启用时才配置或下载嵌入模型。数据模式、平衡与高压缩同时作用于磁盘和上下文，须能按既有权限回查授权原文，准确率不得下降。技术选型及验证方法见[运行路线](technical/runtime-route.md)与[压缩设计](technical/compression-and-performance.md)。

## 如何核对冻结输入

[SHA-256 清单](research.sha256) 收录研究入口、七份 Markdown 分册、回放脚本和结果 JSON 共 10 个文件。路径相对仓库根目录。原文仍在 `research/`，本记录以内容指纹标识读取的版本。它也便于在研究目录发生后续编辑时定位差异。从根目录执行：

```sh
shasum -a 256 -c docs/v2/research.sha256
```

本次采用全新数据模型、宿主契约和界面设计。首个实现切片从空的 V2 数据目录起步。旧库导入、旧 API 别名、旧 UI 路径和就地迁移均无兼容验收项。新服务自身的备份恢复、撤回水位及新旧策略切换仍属 V2 的产品承诺。
