# 运行、替换与验收

## 一个服务怎样启动、停机和重试

P0 在 macOS、Windows、Linux 上分别运行一个当前用户的回环服务，内含消费持久待办的后台执行器，同一服务提供管理网页。首次 `bmem init` 在默认或用户选定的数据根建库。各入口统一按显式 `--home`、本机持久定位、首次安装默认根的顺序选择路径，核对活动定位、根内实例 ID 和运行服务身份。服务停机时普通 CLI 写命令只拉起已核验的实例，恢复连接后才提交；Web 可通过 `bmem web` 重连同一服务。隔离测试使用独立的定位目录、数据根及宿主配置。服务按当前 OS 用户读取凭据，备份与领域导出排除端点密钥和宿主令牌。[数据根解析、故障与重装](cli-and-platform.md)

| 阶段 | 执行行为 | 可观察结果 |
|---|---|---|
| 启动 | 在已登记根验证实例、库格式、WAL、FTS5、受控目录和待办，恢复过期领取并载入当前配置。提炼和向量分别展示最近的验证状态；向量默认关闭，跳过嵌入端点探测、模型加载和索引作业 | 所有者 `health` 给出运行实例 ID、解析后的根和逐项能力。启动失败时 `doctor` 显示实际根及失败阶段；既有数据不可用时不创建替代库 |
| 接收模型任务 | 按最早可运行时间从已提交待办领取，短事务记录领取与输入版本。事务外执行，成功后提交结果及完成状态 | 任务唯一键使重复领取可复用同一裁决。服务重启后能接续，领取时限届满的任务重新可领取 |
| 失败或积压 | 暂时端点错误指数退避并记录下次时间；无权限/输入已失效则结束本次任务；持续失败进入可诊断的停候，可按同一目标重试 | 控制台给出种类、最老年龄、失败原因和受影响能力。模型停机时原文仍可收录、确定声明可生效、授权与词法可用 |
| 停机 | 停止接收新请求和领取待办，在途权威事务提交或回滚，保留未完成的领取记录 | 重启不出现接受回执已返回但证据/待办缺失的状态 |
| 观测 | 记录请求耗时/预算、授权决定类别、调用目的地类别、投影水位差及实际运行工件 ID | 不采原句、凭据、提示词。区分本地服务选中、宿主实际装入、可归因的动作和任务结果 |

### 词法、关系和社区的可替换读路径

P0 给 FTS5 分开写原始词频字段和中文/标识符扩展字段，命中 ID 后按当前权限补读同一事件或任务的邻句；按项目、组件、版本和工件消歧。任务包返回目标、已完成动作、最后验证状态、未结事项和出处，遇到两个不可区分的任务保留两组候选。“为什么得出这一条”沿已证实的依据边直接查，生成端点停机时仍可解释已提交的事实。

P1 对“换种说法的旧问题”比较向量召回和有界窗口，对“谁依赖什么”在许可谓词/步数/候选上限内逐跳出示原文，对“有哪些主题”再试社区。每个投影在已授权域内构建，登记输入快照、分词/模型或算法/种子、维度（向量）、字段范围、授权水位及 `applied_seq`。社区报告逐点绑定输入修订，撤权后连标题和成员统计一起失效。数据不足时可只做授权实体的临时聚合。[关系与社区判据](../../../research/reassessment-2026-11/knowledge-graph.md)

更换投影时从快照旁建，追补建立期间的变更至同一水位，核对授权正反例及错例后原子切换读取指针。切换失败继续读已验证版本或降级到词法；即使索引暂旧，过期内容也不能通过最终授权读取。更换提炼器先做相同输入的旁路候选比较，再让候选进入同一个权威提交端口。若更换权威库存储，则以领域导出恢复并校验，短暂停写、补齐增量、单写者切换；新库接受写入后须将切换期间的增量回放至旧库才能回退。

### 撤回、清理和恢复

| 动作 | 立即责任 | 后台/报告范围 |
|---|---|---|
| 来源上游明确撤回 | 给来源旧版本建立禁读水位；拒绝旧句柄、未发送的衍生包和重复回填，依据仍存也不能供普通读取 | 逆向定位原文、附件、OCR、摘要、社区、索引、暂存、受管备份等，按承诺清理或重建。源端只返回暂不可达时记录覆盖缺口 |
| 主动遗忘 | 受影响内容退出授权读取，保留无正文墓碑以阻止同一对象重导 | 单据逐项记哪些已清理、失败、未能核验及已发出的宿主/外部副本。可读性、受管文件移除和物理介质擦除的观测范围分别说明 |
| 制作受管备份 | SQLite 一致性快照固定 `change_seq`、撤回水位、格式和附件哈希清单 | 按快照引用固定附件至归档完成；核对缺件/哈希。独立撤回清单有库世代、覆盖范围、起止水位及完整性摘要，可随最新清单独立移交 |
| 领域导出 | 对选择范围应用导出用途授权，写稳定 ID、版本、事实时间/知晓区间、依据/派生、许可、墓碑、游标和准许的附件校验值 | 记录导出范围、截止点和文件校验；已移交副本列为外部，跨存储恢复可用公共查询重放核对 |
| 原机或新目录恢复 | 先在隔离区核对备份与附件、应用已知最新且连续的撤回清单。原机以现库最新撤回为下界；新机从独立保存的可信水位取得后续撤回 | 重建投影，检查已撤回对照为零、合法对照仍可读、来源/端点需重新授权情况。通过才允许切换读写；预览后现库水位改变要重做比较 |
| 只剩删除前孤本 | 仅作为隔离历史快照，展示可证明截止点以及清单缺口 | 保持普通服务关闭；补入可信撤回清单并重新预览后才可切换。受管备份中的旧内容需重制已清理包或销毁对应受管备份，并展示单据进度 |

**迁移本机数据卷。** `restore preview` 的可选 `--target-home <绝对路径>` 对应 Web 的目标目录。所有者会话仍连当前登记实例；目的卷必须为可用本地卷，目的目录为新建或空目录。预览把规范化目标、原实例及权威水位绑定到 `preview_id`。迁移须覆盖源实例的全部已接受写入和最新撤回；源水位已推进或归档落后时，先更新备份和预览。应用时取得维护锁，排空并暂停原实例写入，在目标完成核验、保留本机实例 ID 后原子替换定位文件，再重登记带绝对根的启动项及宿主绑定。维护单记录原、目标与切换阶段；重启先按照该单接续，确认仅新根服务后才开放业务写。旧登记与定位不符即拒绝启动，旧卷副本计入本次受管清理单。仅做预览时活动服务及定位保持原样。

### 从反馈到可停用的策略

P0 分开记录 `provided`、`loaded`、`used`、独立任务结果和未知归因。P2 按下列节点记录不可变清单与依赖；每次正式启用有一个可回到合格工件的活动指针。[学习与撤权依据](../../../research/reassessment-2026-11/feedback-learning.md)

1. **数据集。** 授权目的、计算环境和根来源版本均允许才可纳入。样本保留查询/尝试、候选及曝光、标签依据、目标、时间截止点和根来源。按共享根和任务族的连通分组合并，再按时间隔离训练/验证/冻结任务；彻底移除答案和未来修订。授权撤销在新导出和发布前生效。
2. **评测。** 在相同候选、读模型、任务起点、token/时间预算下比较确定性规则与候选，分开报告来源覆盖、最终送达证据充分率、任务通过及成本。明确纠正改变个人事实可立即生效，自评通过不能给包内每一条记忆标正。
3. **发布。** 记录训练清单摘要、父工件、运行配置、冻结报告、影子比较和目标范围。硬约束通过后在预先约定的收益/资源条件内逐步启用。影子只观测检索与延迟，真实效果另由获准小范围试用观察。运行端回报实际加载 ID 才算该范围切换完成。
4. **撤权或回滚。** 停止受污染快照/工件的新训练与发布。若要求消除训练影响，递归查样本、父子工件和部署，停用所有受影响后继，回切到已验证且从未用过该来源的工件或规则，再以干净快照重训评测。普通回滚只换策略指针；既有错发事实按证据追加纠正修订。外部已导出工件独列不可核验范围。

## 验收记录怎样判读

以下是实施后的验收目标。先用空 v2 数据根、合成来源和受控接收器验证权限矩阵。首发联调使用 **Claude Code 与 Codex** 的真实会话和可独立核对的工件，实录各宿主版本、上下文接入能力和实际接收路由。先通过声明链路，随后运行基础自动提炼；优先走真实本机模型，仅在该提炼用途与实际目的地已获准时送往其他真实端点。若某项缺少真实输入、模型产出或宿主回执，应明确列为未通过该项联调。合成接收器的本机/云端分类不预设两款真实宿主的模型目的地。

| 阶段 | 通过公共入口安排的场景 | 可判定结果 |
|---|---|---|
| P0 · 首先通过声明与装入 | Claude Code 与 Codex、两维度、单项改口，另一宿主无关键词启动；随后重建上下文、重连、缩预算并加仅搜索客户端 | 已授权接收者拿到正确组合且原文仍隔离。回执绑定本次模型输入；无能力、待送达和遵循结果分别展示；模型停机不影响明确声明 |
| P0 · 声明通过后接基础自动提炼 | Claude Code 进行普通对话并实际执行溪桥测试工件，工具产出“解析通过，入库仍超时”。真实获准模型自动提炼；Codex 新会话继续任务。另在 Codex 产生普通消息与工具事件，核对两款来源适配器 | 保存输入事件/原文位置、作业、实际模型/模板版本、候选、裁决修订及 Codex 的真实装入与结果。普通用户话语可按出处找回，工具结果标明正负，计划没有被提升为已执行。记录不带“记住”的输入，无人工录入事实 |
| P0 · 提炼中断与补跑 | 临时停掉同一提炼端点，上报两条普通事件；其中一条撤回，随后恢复端点与 worker | 停机时模型能力降级，声明和词法可用；恢复后有效输入真实生成一次可检索修订，被撤回输入停止处理。以事件/模型运行/修订和实际读回核验，队列归零只是运行观察 |
| P0 · 接力与时态 | 溪桥两个并行任务，含计划和实际回执；补录较早配置，再设置未来变更 | 任务/工件正确或明确给出候选；接手卡能指到验证步骤。固定业务时点换知晓时点可得到不同、有据的答案；迟到不倒置现值 |
| P0 · 撤回与灾备 | 受权/无权目的地，保留可合法读取对照，依次测搜索、补读、包、历史；让 worker 暂停，重投撤回前来源、恢复旧包 | 新读取立即不再泄出，合法对照仍读得到。原机与“新目录＋更新撤回清单”均无复活，新目录孤本停在带截止点的预览。已送出范围可核对 |
| P0 · 崩溃与恢复 | 来源页提交前/后分别中止，重发相同页；模型端超时、更正后重试旧提案 | 页和游标一致，单一接受记录与待办、已撤回旧版本不复活，已接受新声明优先 |
| P1 · 增强 | 在跨案例方法归纳中加入新工件版本的失败反例并核对适用条件；独立任务簇分别测短中文实体、标识符、同名负例、词面不重合、需邻句/多跳及无答案，另设给金标证据上限组 | 同预算报每簇改进/退化、充分证据与无依据输出、p50/p95、重建成本；关闭增强时声明、词法、证据追溯仍可用 |
| P2 · 学习与发布 | 按根来源隔离冻结集，配对比较基线、声明、增强；先影子，再授权试用，再撤某个含训练样本的来源 | 区分任务、逐项采用与增量效果；无隐私违规、退化和成本在预定界内才扩大。旧部署及其污染后继均能定位，回退后新声明仍有效 |

对选型，记录运行硬件、冷/热、声明与词法/补读耗时、最老待办、宿主实际 token、峰值内存及每个成功任务成本。硬约束任何一次可核验违规都须阻止放行；收益阈值、最大等待时长和上下文预算在打开冻结结果前登记。研究已有的检索和恢复数据只说明旧工作树上的具体观察。[评测协议](../../../research/reassessment-2026-11/evaluation.md) · [本地证据](../../../research/reassessment-2026-11/local-evidence.md)
