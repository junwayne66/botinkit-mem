## 未能完成的主要原因

| 特性 | 缺少的当前版能力与已有的证据 |
|---|---|
| F01 | 当前版未提供具名时区分句、收件时钟控制、任务级临时约定及逐分句未决原因。真实宿主桥接可观测模型请求，代码输出依从性仍需能执行该任务的模型和正确的约定输入 |
| F02 | 现有 `loaded.complete` 确认声明。实测同一上下文再次交付时，声明快照为 `unchanged`，旧检查和新重试仍同时进入任务包。缺证据留存摘要、任务包模式、证据装入和采用的完整观测 |
| F03 | 作业列表返回 200，导入逐项结果路由返回 404。用 F03-03 和 F03-04 的相同原文探测来源页重投与新请求去重。逐项提炼去向、分页水位和独立来源关系仍缺对应输出 |
| F04 | 现有所有者入口接受 `lexical`、`vector`。多个原样本的 `hybrid` 请求均返回 422。缺并集、名次、同次执行补读和固定候选对照 |
| F05 | 单根拒读和降温治理预检返回 404，缺双读者前后试算及派生依赖。旧包导入空实例实测 `blocked`、`can_apply=false`，查询为空。备份时间使用本次实际创建时间 |
| F06/F07 | 现有原文、声明回执和独立结果可以分别核验。当前缺方法版本及反例的对照声明、纠错生成评测用例、用途冻结集、策略发布和回退等入口 |
| X01/E2E | 缺各样本要求的替换实现、第二权威后端或组合链路。现有来源级撤回和双宿主插入通过旁路回归 |

逐条原因包括缺少的接口或观测，以及已有探针指针。可在 JSON 的 `cases` 按 ID 或 `reason_code` 查找。[134 条判定明细](baseline-2026-11-27.json) · [原始响应、模型请求证据块及接口探针](observations/baseline-2026-11-27-raw.json)

| 项目 | 本次口径 |
|---|---|
| 二进制 | `bmem 0.2.0`。本机安装版与 `src/v2/bmem/target/release/bmem` 的 SHA-256 一致，均为 `d0e36329b8de767013e0dd3a58c220df67e1d634aa04d9efb6689509226f02b1`。仓库 HEAD 为 `12ba926685005eb236045b0aaea5072ffe4c6cb5`，工作区有未提交修改。比较以实际二进制哈希为准 |
