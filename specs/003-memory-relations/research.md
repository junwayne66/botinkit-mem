# Research · 已有实现与最小边界

- 现有图谱 API 直接返回 Store 结果，SVG 已能画边。首页最新24节点可能互不关联，完整页仅截取最新240节点，非空缓存会持续复用。
- `sources.derived_from` 表示实际派生，`root_source_id` 支持真实共同来源。修订沿用记忆ID，`revisions.supersedes`保存版本顺序。
- 第一切片采用已有派生边、共同来源枢纽和最近上一版节点，详情引用原始记录。独立节点保持独立。
- 活动依赖需过滤失效来源，隐私遗忘包含历史来源。自定义根的多级回退需把已访问记忆纳入引用匹配。
- 事实时间策略覆盖声明和候选入口。原始事件发生时间继续服务会话上下文，新增事实时间独立表达明确生效日期。
- 明确声明与验证结果视为可信度相近，低置信推断保持待确认。同时间的未消歧冲突保留。
- 只读队列评估确认普通蒸馏和快速证据归档吞吐差异，任务完成计数与当前有效记忆增量分开报告。当前测量期间调度配置由用户决定。
