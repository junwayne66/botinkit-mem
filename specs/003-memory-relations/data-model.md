# Data Model

## Graph projection

节点包含唯一 `id`、`node_type`，以及实际记忆ID、修订号或来源根/事件ID。记忆、修订、共享来源分别投影现有 `memories`、`revisions`、`sources`。

边包含 `source`、`target`、`relation` 和实际 `evidence`，证据保留来源行ID、事件ID、创建及失效时间。关系类型采用 `derived`、`evidence`、`supersedes`。删除和私密边界覆盖所有端点。

## Fact time

声明和候选接受可选 `effective_at`。事件、当前记忆与修订分别增加可空TEXT列，数据库版本为2。原事件发生时间和入库时间分别保留，旧行通过已保存的发生时间兼容读取。迁移只添加缺失列，旧备份恢复复用相同迁移。

当前记忆与当前修订的事实时间表示最新可信确认水位。同值确认推进水位并保留原正文及修订号，各次确认的原始日期可通过来源事件和审计追溯。正文修订保存历史版本及其水位。普通候选采用事件明确时间，其次采用候选明确时间，最后采用事件发生时间。内部重算采用候选明确时间，缺省保留目标水位。

事实身份继续采用带主体含义的 `fact_key` 与精确 `conditions`，当前正文更新复用版本和派生失效机制。

较新T1/T2事实接受为active后，同键和精确条件内时间更旧的disputed记录转为retracted，退出FTS及当前召回。原正文、修订和来源保留，决策记录通过resolved_by_newer_fact关联本次事件及当前记忆。用户显式版本纠正可以处理等时争议。已解决旧分支复用既有派生失效机制，同来源根下保护本次接受的当前记忆。收束条件同时比较本次输入的原始信任与事实时间。
