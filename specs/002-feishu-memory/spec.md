# Feature Specification — 飞书与 Lark 记忆连接

**Created** 2026-11-13

**Status** Ready for planning

**Input** 用户要求通过 `bmem connect feishu/lark` 自动安装官方 CLI、引导认证授权、首次多选私聊/群聊/文档历史，并提供等价 Web 配置。

## User Scenarios & Testing

### US1 一键连接与授权（P1）

用户选择飞书或 Lark 后，系统准备官方连接工具，展示安装进度和浏览器授权入口，完成后呈现真实连接状态。

1. 未安装时自动准备官方工具，用户无需填写可由系统确定的安装参数。
2. 已安装且可用时复用，重复连接不破坏已有配置和认证。
3. 授权未完成、失效或缺少读取权限时明确显示当前步骤，可重新发起。
4. URL 和二维码同时提供，认证完成可继续后续步骤。

独立验收通过命令行和 Web 发起同一连接流程，覆盖安装、等待授权、成功与失败恢复。

### US2 首次历史范围选择（P1）

首次连接时用户决定是否读取历史，可多选私聊、群聊、飞书文档，也可暂不读取。

1. 未确认读取范围时不请求历史业务内容。
2. 只读取用户选择且已获授权的类别，三种类别可任意组合。
3. 选择可保存并修改，再次连接可查看已保存选择。
4. 导入保留账号、品牌、对象、时间与来源，重复导入保持幂等，失败可继续。

独立验收使用受控官方协议端点验证全部范围组合、分页、重复与失败重试，检查真实事件入口及来源。

### US3 Web 与命令行一致（P1）

用户可在来源页完成连接、授权、范围选择和导入，在命令行查看并继续相同配置。

1. Web 选择飞书/Lark并启动，安装或授权不会阻塞页面。
2. 命令行交互支持多选，同时提供非交互参数，后台服务显示相同状态。
3. 两端显示导入进度、最后成功时间与可操作错误。

独立验收使用真实本地 API、CLI 子进程和浏览器完成一致配置与失败恢复。

### Edge Cases

- 官方工具下载失败、平台不支持、用户未完成授权。
- 权限不足、令牌过期、账号变化、空历史、分页中途失败。
- 已选择范围被取消，后续读取停止，已导入记忆沿用现有遗忘能力处理。
- 用户重复点击连接或同步，界面显示正在进行的同一操作。

## Requirements

- FR-001 支持 `bmem connect feishu` 与 `bmem connect lark`，保留已有三类 Harness 接入。
- FR-002 自动安装用户指定的官方 larksuite/cli 工具，展示准备进度，可复用可用安装。
- FR-003 引导官方浏览器配置和认证，用户只处理官方交互和功能范围选择。
- FR-004 从真实认证状态判定已连接，向用户展示 URL、二维码、到期和失败恢复入口。
- FR-005 首次询问是否读取历史，私聊、群聊、文档可多选或全部不选，保存明确选择。
- FR-006 历史读取严格遵守选择与账号实际权限，仅申请该功能所需读取能力。
- FR-007 导入保留来源和版本身份，使用现有持久事件与治理流程，重复或续传不增重复事件。
- FR-008 CLI 与 Web 使用同一连接配置和服务状态，后台执行耗时步骤。
- FR-009 支持按已选范围手动导入和后台增量采集，并能看到积压、错误和最后成功时间。
- FR-010 凭据交由官方 CLI 管理，不写入记忆、API响应、规格或日志。授权挑战仅作为当前流程临时状态。
- FR-011 飞书输入保留外部来源信任，以可检索引用资料保存，默认私密，可明确选择允许云端召回，不提升为用户对 Agent 的直接指令。
- FR-012 回环地址、现有三个 Harness 接入、历史导入和本地模型运行行为保持可用。

## Key Entities

- 连接配置，包含品牌、已确认范围和启用状态。
- 授权流程，包含当前阶段、临时授权入口、有效期和脱敏错误。
- 导入游标，包含品牌、账号、对象、分页水位、最后成功与计数。
- 来源事件，包含外部对象身份、正文、发生时间、出处与私密标签。

## Success Criteria

- SC-001 首次用户在 CLI 和 Web 均可通过品牌、范围选择与官方授权完成连接，无需填写应用密钥或命令参数。
- SC-002 三种历史类别的八种选择组合均按范围读取，空选项读取历史内容的请求数为零。
- SC-003 重复读取同一历史对象，事件数保持不变，中途失败可继续完成。
- SC-004 两端配置和状态一致，长操作期间可查看进度并继续其他记忆操作。
- SC-005 原有单机回归与新增公开入口验证通过，凭据及私密正文不出现在默认云端召回。

## Assumptions

- 使用者拥有飞书或 Lark 账号，并有目标聊天和文档的读取权。
- 官方一键创建应用和 OAuth 可能要求组织管理员批准，系统展示官方返回的下一步。
- 首次范围默认全不选，选择可在连接过程中保存，所需只读授权由系统推导。
- 连续同步沿用所选类别，历史读取完成与提炼完成分别展示。
- 本轮扩展单机记忆服务，支持 macOS/Linux 中官方工具提供的安装平台。
