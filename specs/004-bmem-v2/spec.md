# Botinkit Memory V2 首发功能规格

2026-11-19。技术与验收以仓库 `docs/v2/technical/` 的 R3 和 `docs/v2/product/acceptance.md` 为准。代码目录采用用户批准的 `src/v2/{bmem,web}`，测试为 `tests/v2`，数据为 `tests/v2/data`。

## 用户故事

1. 作为本机用户，我可以初始化唯一数据根，并用 CLI 或 Web 查看和更改同一份设置。版本冲突应显示明确结果，向量关闭时不发起 embedding 请求。
2. 我能追加或纠正声明，查阅证据及每个维度的历史。获准宿主在下一个可控模型调用收到新值，不必等待模型或后台索引。
3. 我能把获准会话中的普通话语和工具结果提炼成可追溯记忆。更新、撤回、独立来源、失败重试和三档输出须保留来源与权限。
4. 我能查看提供、装入、采用、独立验证和未观察状态，暂停或撤回来源、备份和隔离恢复。
5. 我可在 macOS、Linux 和 Windows 安装并升级原生程序，运行同一套可验证流程。

## 成功标准

- 配置、声明均以两入口真实写入和回读验证，冲突、重放及未授权拒绝需有负对照。
- 双宿主以真实会话确认入站和出站观察；普通话语与工具回执需过真实生成端点，独立验证推断准确与来源定位。
- 对照原生平台、空库初始化、数据保护、压缩质量与性能；只按实测范围标记验收状态。

## 所有者工作台

产品界面与项目介绍显示 Botinkit Memory，终端命令使用 `bmem`。工作台支持用图谱追溯主题社区的实际关系，用来源、事件与时间分布判断数据库状态，并在同一配置版本上完成 CLI 与 Web 双向修改。验收覆盖空库与有数据的图谱、撤回、移动端、键盘操作、减少动态效果、来源导入重试、过期配置以及中文原话检索。[交互设计](../../docs/v2/ui/README.md)
