# Botinkit Memory V2 首发功能规格

2026-11-19。技术与验收以仓库 `docs/v2/technical/` 的 R3 和 `docs/v2/product/acceptance.md` 为准。代码目录采用用户批准的 `src/v2/{bmem,web}`，测试为 `tests/v2`，数据为 `tests/v2/data`。

## 用户故事

1. 作为本机用户，我可以初始化唯一数据根，并用 CLI 或 Web 查看和更改同一份设置。版本冲突应显示明确结果，向量关闭时不发起 embedding 请求。
2. 我能追加或纠正声明，查阅证据及每个维度的历史。获准宿主在下一个可控模型调用收到新值，不必等待模型或后台索引。
3. 我能把获准会话中的普通话语和工具结果提炼成可追溯记忆。更新、撤回、独立来源、失败重试和三档输出须保留来源与权限。
4. 我能查看提供、装入、采用、独立验证和未观察状态，暂停或撤回来源、备份和隔离恢复。
5. 我可在 macOS、Linux 和 Windows 安装并升级原生程序，运行同一套可验证流程。

## 成功标准

- 配置、声明均以两入口真实写入和回读验证，冲突、重放及未授权拒绝需有负对照。
- 双宿主以真实会话确认入站和出站观察；普通话语与工具回执需过真实生成端点，独立验证推断准确与来源定位。
- 对照原生平台、空库初始化、数据保护、压缩质量与性能；只按实测范围标记验收状态。

## 所有者工作台

产品界面与项目介绍显示 Botinkit Memory，终端命令使用 `bmem`。工作台支持用图谱追溯主题社区的实际关系，用来源、事件与时间分布判断数据库状态，并在同一配置版本上完成 CLI 与 Web 双向修改。验收覆盖空库与有数据的图谱、撤回、移动端、键盘操作、减少动态效果、来源导入重试、过期配置以及中文原话检索。[交互设计](../../docs/v2/ui/README.md)

## 数据模块改版

[Figma 审核原型](https://www.figma.com/design/oI5e0Ix1hUIKOKSeenBp3l?node-id=2-23)使用合成示例展示三个页面及主要操作。用户于 2026-11-21 确认原型和范围，进入并行实现。

1. **数据来源**。所有者可在飞书、Codex、Claude Code 和 DSH 卡片上查看各自的连接与采集状态。飞书区分账号登记、授权检查和历史同步。Harness 区分宿主配置、新会话采集和共享声明读取。页面提供已登记来源表格、最近入库时间和过去七天按来源统计的入库事件图。
2. **数据管理**。原「历史导入」改名。保留 V2 JSON 事件批次导入，先校验目标来源、授权和游标，再预览、确认和显示回执。原型提议按来源及日期导出获准读取的 V2 事件 JSON，展示所选范围、事件数量和导入导出记录。既有入口及链接继续可用。
3. **注入台账**。按真实投递及宿主回执显示提供数、装入已观察数和采用已观察数。记录支持宿主及回执筛选、翻页和详情。部分装入应能从详情核对，缺回执显示待回执。

### 从来源导入历史与连接器扩展

[历史导入原型](https://www.figma.com/design/oI5e0Ix1hUIKOKSeenBp3l?node-id=13-3333) · [添加连接器原型](https://www.figma.com/design/oI5e0Ix1hUIKOKSeenBp3l?node-id=13-3759)

- 已连接来源的卡片提供「导入历史」。数据来源和数据管理也可打开来源选择器。类别默认未选中，用户确认创建后才入队，在数据管理查看对象数、已接收数、重复和分项错误。一次性导入单独授权，持续历史同步和 Harness 新会话采集各自保留原配置。
- 飞书可独立勾选全部私聊、全部群聊和全部可见文档。按已授权账号逐页发现和读取会话，群聊包含接口可读取的话题回复。文档逐页读取账号和应用可见的新版、旧版及知识库文档正文，正文取当前可读版本。图片、文件等消息记录保留类型与可用名称。
- Codex、Claude Code、DeepSeek Harness 各自从本机读取所有可发现的保留会话，包含用户消息、助手答复和工具回执。导入使用现有来源身份和事件去重规则。任务可取消、查看失败并重试，服务重启从 SQLite 检查点恢复。CLI 保留指定对象和时间窗口的入口。
- 「添加连接器」展示已接入和候选连接器。Hermes、OpenClaw 和第三方 MCP 首轮是拟支持项，接入状态以目标版本及数据能力验证为准。第三方 MCP 仅对用户指定的服务与资源进行显式预览和导入，分页、稳定标识与增量能力由适配器的实际契约决定。

### 验收场景

- 已授权的飞书账号、Harness 采集开关和共享声明授权可在浏览器重新加载及守护进程重启后回读。CLI 更改可在前台页面自动反映，返回前台或执行操作成功后立即读取。第一次读取中、读取失败以及上次已知值过期有独立反馈。未验证的旧飞书登记显示核验状态。
- 用同一隔离 SQLite 的已知记录对账来源表、入库图、台账和审计记录。空库显示真实空态。授权中的临时过程、宿主可执行文件检测及数据库内业务配置各有明确文案。
- 导入文件匹配目标来源和游标时进入现有幂等提交流程，重复提交可核对同一结果。导出需核对来源、日期边界、事件数及数据读取权限。导出文件保留可核对的来源、原生标识和事件时间，撤回或失去读取授权的原文、授权 token 和凭据不进入文件。
- 通过隔离夹具验证分类多选、空选择、授权范围、多页目录、群聊话题、新旧版及知识库文档。覆盖三个 Harness 的全部本机历史、归档会话、重复导入、部分失败和重启后重试。打开对话框或只勾选时不创建作业。一次性导入不切换持续采集，两者重叠的事件只入库一次。
