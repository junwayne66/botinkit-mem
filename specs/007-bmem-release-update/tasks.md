## 2026-11-27 实施状态

macOS arm64 用三份固定版本程序通过 U01–U07、U09。Windows 独立更新与恢复助手已纳入代码，U08 仍需实际 Windows EXE 占用验收。T005 的平台启动器、T009 的 Windows 原生切换、T013–T015 的正式签名与跨平台发布证据保持待验。每项发布证据及原样本回归在[验证记录](validation.md)。

后续补齐了安全清理终态恢复点的实现及实跑验证。各原生平台的覆盖范围和正式发布依赖见[补齐轮验收](closure-validation-2026-11-27.md)。

Windows x64 与 ARM64 各通过两条原生 U08 和一条 Task Scheduler 接管。U08 覆盖旧 stdio 占用、Win32 共享冲突和替换中断恢复。计划任务保持配置和原实例，分别恢复运行与初始停止状态。[Windows 原生验收](closure-validation-2026-11-27.md#windows-原生验收)
