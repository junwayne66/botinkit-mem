### Edge Cases

覆盖重复乱序、无答案、时区歧义、无回执、跨任务同名、治理先于后台完成、旧库及旧备份。

## Requirements

- FR-001 支持项目、任务、有效期和原话解释，兼容现有报告规则。
- FR-002 权限在截断前约束候选，计划与最新检查均可定位，交付、装入、采用和结果分别核验。
- FR-003 页回执、游标、待办同事务，逐项结果与分页可回放。
- FR-004 融合和补读均遵守读者、用途、预算、版本及任务范围。
- FR-005 治理确认即影响实际读取。支持组内为联合必要条件，完整替代组可支持重新归纳。
- FR-006 工件条件、支持与反例决定方法适用性。按当前权限和时效验证。
- FR-007 评测和训练用途独立。回切策略保留用户纠正和墓碑。
- FR-008 权威存储、授权和身份由现有领域管理。外部实现按稳定引用提交结果。
- FR-009 按相同 ID 和哈希对齐 134 条验收，报告每条状态与观测。

### Key Entities

来源根及版本、声明或方法修订、任务尝试、交付与装入清单、导入作业与页、候选裁定与支持组、评测用例与策略版本。

## Success Criteria

- SC-001 每项改动以原样本验证，覆盖真实入口及两宿主入参。
- SC-002 同一套 134 例与 652 条断言前后对照。独立结果未知单列。
- SC-003 记录应用二进制、样本指纹及逐条观测。缺执行条件须记录明确阻塞。

## Assumptions

使用单机 SQLite 和既有 CLI、Web、绑定宿主。005 通用 Agent 接口按独立签收执行。
